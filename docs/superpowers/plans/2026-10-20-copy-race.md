# Copy Race Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: the skill the **Execution:** line names — dr-superpowers:subagent-driven-development for `subagent`, dr-superpowers:executing-plans for `inline`. Steps use checkbox (`- [ ]`) syntax for tracking.

> **External executors:** codex

**Goal:** Close register row DM 68: both mirror-to-checkout moves write the buffer they read, with an exclusive create, instead of reopening the mirror's file with a following, blocking `copyFileSync`; release dforge 4.2.3.

**Architecture:** `progressToLocal` already holds each mirror file's bytes, so its copy becomes an exclusive `writeFileSync` of that buffer. `documentsToLocal` reads each mirror file once without following links or blocking, checks it against the hash darkmem confirmed, writes it exclusively, skips a destination a killed run left equal, reads its copies back without following links, and turns every file-system failure in that loop into a refusal instead of a crash.

**Tech Stack:** Node ES modules with `node --test`, Markdown.

**Spec:** docs/superpowers/specs/2026-10-20-copy-race-design.md

**Execution:** inline — `claude --model sonnet --effort medium` — no task is heavy (highest total 3, risk 2) and none carries an Executor line

## Contracts

- **Refusal lines (Task 1 keeps, Task 2 adds).** A move answers `{ moved: false, reason, details }`; `reconcile` prints `darkmem-sync reconcile: documents stay darkmem (configured local): <reason>` and each detail as `  <detail>`. `progressToLocal` keeps its reasons and details unchanged. `documentsToLocal` adds, with `<name>` the repository-relative path such as `docs/dforge/specs/b.md`:
  - `docs/dforge changed during the move; nothing was overwritten` — details `<name>: changed during the move; not overwritten`, then `<name>: copied` per file written this run.
  - `the mirror changed during the move; nothing more was copied` — details `<name>: the mirror's copy changed after darkmem confirmed it`, then any `changed during the move` lines, then the `copied` lines.
  - `a copy into docs/dforge failed (<code>); the files copied so far stay, and a rerun copies the rest` — details the `copied` lines.
  - `a copied file differs from the mirror's` (kept) — details `<name>: differs from the mirror's copy`, then the `copied` lines.

`documentsToLocal` copies with `fs.copyFileSync(file, dest)`: no exclusive flag, so it follows a link at `dest`, truncates what stands there and blocks on a named pipe, and it reopens the mirror's file the same way. Its read-back, `fileHash(dest)`, follows links, and nothing in the loop is inside a `try`, so a file-system error crashes reconcile. The tests run the move in-process, offline, so `t.mock.method(fs, …)` reaches it; the subprocess helper (`s.reconcile()` of `darkmemDocs`) does not see mocks. Every `writeFileSync` mock keys on a path: `reconcile` also writes its stores file through `writeFileSync`.

```js
// Documents applied darkmem and configured local, the mirror holding
// specs/a.md and specs/b.md with their sync state, moved in-process so a test
// can mock fs. Offline (darkmem turned off) the move needs no client.
const SYNCED = { "dforge/specs/a.md": sha("# A\n"), "dforge/specs/b.md": sha("# B\n") };

function offlineDocs() {
  const repo = makeRepo();
  const home = mapped(repo, { entry: { documentStore: "local", progressSource: "local" }, stores: { documents: "darkmem", progress: "local" } });
  write(path.join(home.docsRoot, "specs", "a.md"), "# A\n");
  write(path.join(home.docsRoot, "specs", "b.md"), "# B\n");
  const cfg = { ...cfgFor(repo, home.env), enabled: false };
  const state = loadState(cfg.statePath);
  state.documents = { ...SYNCED };
  const lines = [];
  let persisted = 0;
  const context = { cfg, client: null, env: home.env, out: line => lines.push(line), report: { refused: 0 }, state, persist: () => { persisted += 1; } };
  return {
    ...home, repo, lines, state,
    persisted: () => persisted,
    mirrorCopy: rel => path.join(home.docsRoot, ...rel.split("/")),
    dest: rel => path.join(repo, "docs", "dforge", ...rel.split("/")),
    reconcile: () => reconcileInProcess(context),
  };
}

const STAY = "darkmem-sync reconcile: documents stay darkmem (configured local): ";

// A refused move keeps the mirror and its sync state, and a.md, written
// before the refusal, holds the mirror's content.
function assertKept(s) {
  assert.equal(fs.existsSync(s.docsRoot), true, "the mirror is not set aside");
  assert.deepEqual(s.state.documents, SYNCED);
  assert.equal(s.persisted(), 0);
  assert.equal(read(s.dest("specs/a.md")), "# A\n");
}

// Runs `act` once, when the move makes b.md's directory after writing a.md:
// between b.md's checks and its write. Returns how often it ran.
function beforeSecondWrite(t, s, act) {
  const mkdir = fs.mkdirSync;
  let ran = 0;
  t.mock.method(fs, "mkdirSync", (dir, options) => {
    const made = mkdir(dir, options);
    if (dir === path.dirname(s.dest("specs/b.md")) && fs.existsSync(s.dest("specs/a.md")) && !fs.lstatSync(s.dest("specs/b.md"), { throwIfNoEntry: false })) {
      ran += 1;
      act();
    }
    return made;
  });
  return () => ran;
}

test("a file that lands in docs/dforge just before its write is never overwritten", async t => {
  const s = offlineDocs();
  const ran = beforeSecondWrite(t, s, () => fs.writeFileSync(s.dest("specs/b.md"), "# B local\n"));
  await s.reconcile();
  assert.equal(ran(), 1);
  assert.ok(s.lines.includes(`${STAY}docs/dforge changed during the move; nothing was overwritten`), s.lines.join("\n"));
  assert.ok(s.lines.includes("  docs/dforge/specs/b.md: changed during the move; not overwritten"), s.lines.join("\n"));
  assert.ok(s.lines.includes("  docs/dforge/specs/a.md: copied"), s.lines.join("\n"));
  assert.equal(read(s.dest("specs/b.md")), "# B local\n");
  assertKept(s);
});

test("a link that lands at a docs/dforge destination after the comparison is never written through", { skip: process.platform === "win32" }, async t => {

test("a link that replaces a written copy before the read-back is never read through", { skip: process.platform === "win32" }, async t => {
```
